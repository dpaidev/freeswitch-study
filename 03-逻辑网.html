主干边关系

main() → switch_core
switch_core → session
session → channel
channel → event
channel → media
media → codec
codec → resample
resample → RTP
RTP → jitterbuffer
module loader → ASR 接口
ASR 接口 → IVR
IVR → 业务逻辑

真实文件对应

  • src/switch.c：main()
  • src/switch_core.c：switch_core
  • src/switch_core_session.c：session
  • src/switch_channel.c：channel
  • src/switch_event.c：event
  • src/switch_core_media.c：media
  • src/switch_rtp.c：RTP
  • src/switch_jitterbuffer.c：jitterbuffer
  • src/switch_loadable_module.c：module loader
  • src/switch_core_asr.c：ASR 接口
  • src/switch_ivr_async.c：IVR
